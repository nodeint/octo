# @workspace/ds

Design system: tokens, variants, recipes, appearance axes, and base styles. It has no dependency on `@workspace/ui`.
Entry: `@workspace/ds/styles.css`. It declares the cascade layers; the consumer imports its component CSS into `components`.

Folders: `theme/`, `layout/`, `variants/`, `recipes/`, `appearance/`, plus `reset.css`, `base.css`, `typography.css`, `components.css`, `utilities.css`.
The Recipes and paint-variant rules are still documented in `packages/ui/README.md` and have not been moved yet.
